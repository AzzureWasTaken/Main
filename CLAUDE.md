# MineX banner ads: standing notes

Work lives in `ads/banners/`. The only banner kept is the **sponsored-style remake** (`minex-*-v3-*` GIFs),
generated by `ads/banners/tools/sponsor-banner.py` (see `ads/banners/README.md` for the full pipeline).
The owner uploads the GIFs to Minecraft server-list sites as paid sponsored banner ads.

## Versions (identical apart from the IP)
- `minex-ml-v3-*`   -> `ML.MINEX.GG`
- `minex-mcc-v3-*`  -> `MCC.MINEX.GG`
- `minex-list-v3-*` -> `LIST.MINEX.GG`
A new IP request means "change the IP only": run the generator with the new IP as the third argument, encode the
GIF ladder, add it as a separate section on the graphics board page, update the README size table, commit and push.

## Preferences the owner has set
- The letter **L in the IP is a plain, normal capital L** (straight stem, square foot). Bungee's own L has a curved
  foot that looks wrong, so the IP text uses `tools/sponsor-assets/fonts/bungee-plain-l-400.ttf`
  (`BUNGEE_IP` in `sponsor-banner.py`). Keep it capital. Do not switch back to the stock Bungee L.
- Big "MineX" wordmark: "Mine" is bright white, hand-drawn M and X (the game font's are unreadable at this size),
  X is gold, one row taller than the other letters, and shares their baseline.
- The big logo coin is face-on and circular.
- Each panel has its own props. SURVIVAL: creeper heads, PAYOUTS: gold ingots, EVENTS: firework rockets,
  FREE RANKS: nether stars. Never reuse the same prop on two panels.
- IP text on every panel is large. Eased item entry (about 20 frames), not laggy.
- Recommended upload is the 468x60 `mid` GIF (about 374 KB).

## How the owner works
- Small visual tweaks, one at a time. Do exactly what is asked and nothing more.
- If the owner says "stop", stop immediately and run no more tools.
- Do not start a local server unless asked.
