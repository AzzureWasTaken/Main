# MineX SMP — Reddit Ads Campaign Brief

## Server facts (from supplied creative)

| Field | Value |
|---|---|
| Name | MineX SMP |
| Java IP | `fun.minex.gg` |
| Discord | `discord.gg/minex` |
| Account types | Premium and cracked |
| Hook | Free rank for every new player |
| Status | "New Update" |
| Bedrock IP / port | Not stated — needed |

## Objective

Drive new players onto the server, measured by Discord joins and concurrent
player count.

**Send traffic to the Discord invite, not the IP.** An IP in an image cannot be
clicked, attributed or retargeted — a player has to memorise it and alt-tab. A
Discord invite link is clickable, gives you join counts per invite code, and
builds an audience you can re-engage for free on every future update. Keep the
IP visible in the creative for the people who join directly, but make the
clickable destination the Discord.

Create a **separate invite code per ad variant** (e.g. `discord.gg/minex-r1`)
so Discord's own invite analytics tell you which ad actually delivered players.
That is the cheapest attribution available here and it costs nothing to set up.

## Funnel

1. Reddit feed impression
2. Click → Discord invite
3. Discord welcome channel: IP, version, how to claim the free rank
4. Join server → claim rank
5. Retention: that is the server's job, not the ad's

Step 3 is where most of this campaign will be won or lost. If the welcome
channel does not put the IP and the rank-claim command in the first screen, paid
clicks leak out. Worth fixing before spending anything.

## Budget shape (suggested starting point)

- Start at **$20–30/day total**, split across 2–3 ad sets, for 5–7 days.
- That is enough for roughly 15–40k impressions at typical Reddit CPMs and will
  separate a working angle from a dead one.
- Do not optimise on CTR alone. The number that matters is cost per Discord
  join, and after that, cost per player who actually logs in.
- Kill any ad set that has spent 3× your target cost-per-join without a join.

## Blockers to resolve before launch

These are genuine launch risks, not nitpicks. Details in `creative-notes.md`.

1. **"Cracked" in paid creative** — likely to fail Reddit ad review.
2. **Deadpool skin** — third-party IP in a commercial ad.
3. **Image ratio** — 766×555 is not a Reddit ad size.
4. **Bedrock support** — unknown, and it changes the targeting.

## Open questions

- Is there a Bedrock IP/port, or is this Java-only?
- Which Java versions does it accept (e.g. 1.8–1.21 via ViaVersion)?
- What is the current player count / peak concurrent? Real numbers make
  stronger copy than adjectives.
- What exactly does the free rank give? Specifics convert; "free rank" alone
  does not.
- Is there a store, and is the server pay-to-win? This decides whether the
  anti-P2W angle in `ad-copy.md` is honest and usable.
- Target countries, and is there a region the server is hosted in?
- How old is the server, and is this a fresh world or an established one?
