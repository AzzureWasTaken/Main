# Sponsor-style banner assets

Used by `../sponsor-banner.py` to draw `minex-ml-v3-*`.

| Path | What it is |
|---|---|
| `coin.png` | The MineX coin, cut out of the original banner (`minex-mcl-source.webm`). |
| `fonts/bungee-400.ttf` | Bungee, headline and kicker font. SIL Open Font License. |
| `fonts/lilita-one-400.ttf` | Lilita One, the "MineX" wordmark. SIL Open Font License. |
| `props/*.png` | Transparent 3D renders of Minecraft blocks and items, made by `../props-3d/` from the game's own textures (Mojang). |

The fonts come from the Fontsource npm packages (`@fontsource/bungee`, `@fontsource/lilita-one`),
converted from WOFF to TTF with fontTools.
