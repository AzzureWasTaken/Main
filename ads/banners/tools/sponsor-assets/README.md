# Sponsor-style banner assets

Used by `../sponsor-banner.py` to draw `minex-ml-v3-*`.

| Path | What it is |
|---|---|
| `fonts/bungee-400.ttf` | Bungee, headline and kicker font. SIL Open Font License. |
| `fonts/luckiest-guy-400.ttf` | Luckiest Guy, style 3 headlines. Apache License 2.0. |
| `blocks/*.png` | Minecraft block textures (Mojang) for style 3's block walls. |
| `props/*.png` | Transparent 3D renders of Minecraft blocks and items, made by `../props-3d/` from the game's own textures (Mojang), including `minex_coin` and `minex_wordmark`. |

The fonts come from the Fontsource npm packages (`@fontsource/bungee`),
converted from WOFF to TTF with fontTools.
