# Pixel-banner assets

Minecraft's own textures and font, used by `../pixel-banner.py` to draw `minex-ml-v2-*`. They come from the
[InventivetalentDev/minecraft-assets](https://github.com/InventivetalentDev/minecraft-assets) mirror of the game
files (version 1.20.4). Minecraft textures belong to Mojang.

`ascii.png` is the game font; `lava_still.png` is the game's animated lava strip (20 frames of 16x16).
