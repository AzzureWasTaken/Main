# Mob sprites

Front views assembled from Minecraft's own entity textures, taken from the
[InventivetalentDev/minecraft-assets](https://github.com/InventivetalentDev/minecraft-assets)
mirror of the game files. Minecraft textures belong to Mojang.

| File | Built from |
|---|---|
| `wither_skeleton.png` | `1.20.4/.../entity/skeleton/wither_skeleton.png` (head, body, arms, legs front faces) holding `item/stone_sword.png` |
| `ghast.png` | `1.20.4/.../entity/ghast/ghast.png` (body front face plus five tentacles) |
| `bat.png` | `1.20.1/.../entity/bat.png` (head, body, inner and outer wings, spread) |
| `ghast_shooting.png` | `1.20.4/.../entity/ghast/ghast_shooting.png` (same assembly: squinting red eyes, open mouth) |
| `fireball.png` | `1.20.4/.../textures/item/fire_charge.png`, cropped and brightened so it reads at banner size |
